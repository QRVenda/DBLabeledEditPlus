# DBLabeledEditPlus

Componente para pesquisar registros.  
As funcionalidades extras estão encapsuladas na propriedade "Configurar".

---

## ⚙️ Configuração

Adicione o caminho do componente no **Library Path** do Delphi.

### Caminho a adicionar:
DBLabeledEditPlus\src

### Como configurar no Delphi:
Tools → Options → Language → Delphi → Library → Library Path
